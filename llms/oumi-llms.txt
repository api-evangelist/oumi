# Oumi

> Oumi (Open Universal Machine Intelligence) is an open-source, Apache-2.0 platform for ML engineers and researchers to train, fine-tune, evaluate, and deploy foundation models (LLMs and VLMs) through one unified interface. It ships as a Python library and a first-party CLI, with a hosted managed platform and an MCP server for agentic clients. Generated by the API Evangelist enrichment pipeline from the public Oumi surface.

## Product
- [Website](https://oumi.ai): Oumi AI model development platform.
- [Managed Platform](https://platform.oumi.ai): Hosted Free/Pro/Enterprise product; sign up and run jobs.
- [Pricing](https://oumi.ai/pricing): Free ($0, up to $50 credits), Pro ($25/mo + pay-as-you-go), Enterprise (custom).
